# Percentages and Profit-Loss

**Key points / formula:** Percentage = (part/whole) x 100. Profit % = (SP - CP)/CP x 100. Loss % = (CP - SP)/CP x 100. Successive percentage changes multiply, they don't add (e.g. +10% then -10% is NOT 0% net).

**When it's asked (pattern cue):** Any question with "increase/decrease by X%," discount + markup combos, or cost price/selling price comparisons.

**Worked micro-example:** An item's cost price is 200. It's sold at a 15% profit. Find the selling price.
```
Profit = 15% of 200 = 30
Selling Price = CP + Profit = 200 + 30 = 230
```

**Common gotcha / trick:** Applying successive percentages by simple addition instead of compounding (a 20% increase followed by a 20% decrease is a net -4%, not 0%); mixing up whether profit/loss percentage is calculated on cost price (standard) vs selling price (some problems explicitly state this, changing the formula).
