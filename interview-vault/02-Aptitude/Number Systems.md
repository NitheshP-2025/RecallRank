# Number Systems

**Key points / formula:** Divisibility rules (e.g. divisible by 3 if digit sum is divisible by 3), LCM (smallest common multiple) and HCF/GCD (largest common divisor), remainder theorem basics, and base conversion (binary/decimal/hex).

**When it's asked (pattern cue):** "Find the smallest/largest number divisible by X and Y," remainder-based word problems, or direct base-conversion questions.

**Worked micro-example:** Find the HCF and LCM of 12 and 18.
```
12 = 2^2 x 3, 18 = 2 x 3^2
HCF = 2 x 3 = 6
LCM = 2^2 x 3^2 = 36
Check: HCF x LCM = 6 x 36 = 216 = 12 x 18 (matches)
```

**Common gotcha / trick:** Forgetting the identity HCF(a,b) x LCM(a,b) = a x b, which is a fast way to cross-check answers; making sign/carry errors during base conversion under time pressure.
