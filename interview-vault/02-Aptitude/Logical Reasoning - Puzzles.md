# Logical Reasoning - Puzzles

**Key points / formula:** No fixed formula — solved by systematically applying given constraints to narrow down a fixed set of possibilities (seating arrangement, sequencing, grid assignment), usually via elimination and a table/grid to track deductions.

**When it's asked (pattern cue):** Circular/linear seating arrangements, ranking/sequencing puzzles ("who finished 2nd"), or grid-based constraint puzzles (who owns which pet/house/color).

**Worked micro-example:** 4 people (A,B,C,D) sit in a row. A is not at either end. B is immediately left of C. Deduce possible arrangements by placing the strongest constraint first (A not at ends), then testing B-C adjacency in remaining slots.

**Common gotcha / trick:** Not writing down ALL given constraints before starting to place elements (working memory overload leads to missed conditions); assuming a unique solution exists when the puzzle allows multiple valid arrangements unless a final clue narrows it down — always re-check every constraint against the final answer.
