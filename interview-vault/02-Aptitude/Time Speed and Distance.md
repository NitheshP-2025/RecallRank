
# Time Speed and Distance

**Key points / formula:** Distance = Speed x Time. Relative speed: add speeds when moving toward each other, subtract when moving in the same direction. Average speed for equal distances at two speeds = 2ab/(a+b), NOT the simple average.

**When it's asked (pattern cue):** Word problems involving trains, boats/streams (upstream = speed - current, downstream = speed + current), or two objects moving toward/away from each other.

**Worked micro-example:** Two trains 300 km apart move toward each other at 60 km/h and 90 km/h. Time to meet?
```
Relative speed = 60 + 90 = 150 km/h
Time = Distance / Relative speed = 300 / 150 = 2 hours
```

**Common gotcha / trick:** Using the plain average of two speeds instead of the harmonic mean formula (2ab/(a+b)) when the distances covered are equal but speeds differ; forgetting to convert units (km/h to m/s: multiply by 5/18) before combining with a distance given in meters.
