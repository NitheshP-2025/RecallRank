# Data Interpretation

**Key points / formula:** No single formula — extract exact values from tables/bar/line/pie charts, then apply percentage, ratio, or average calculations on the extracted numbers. Pie charts: value = (angle/360) x total, or (percentage) x total.

**When it's asked (pattern cue):** Any question paired with a table or chart, usually asking for a computed comparison (percentage change, ratio between two categories, or which category is highest/lowest) rather than a raw lookup.

**Worked micro-example:** A pie chart shows Sales at 90 degrees out of 360, total sales = 800.
```
Sales value = (90/360) x 800 = 200
```

**Common gotcha / trick:** Misreading axis scales or units on a chart under time pressure (e.g. chart is in thousands, but the question expects raw units); doing all calculations from the chart visually instead of cross-checking against any given total/legend values first.
